# Nova Browser — проект Android

Исходный проект браузера на Kotlin и Android System WebView.

## Функции первой версии
- Сайты и поиск Google из адресной строки
- Несколько вкладок, переключение и закрытие текущей вкладки
- Назад / вперёд / стартовая страница
- Закладки и локальная история
- Загрузки через Android DownloadManager
- Приватная вкладка: не записывает историю приложения и использует режим без кеша (cookies WebView не изолируются)
- Очистка истории, cookies и кеша
- Переключение светлой/тёмной оболочки
- Поделиться ссылкой через Android

## Сборка APK только с телефона через GitHub Actions
1. На GitHub создайте новый пустой репозиторий `NovaBrowser`.
2. Скачайте и распакуйте ZIP проекта на телефоне.
3. Через сайт GitHub откройте репозиторий → Add file → Upload files.
4. Загрузите ВСЕ содержимое папки проекта в корень репозитория. Включите скрытую папку `.github` и файл workflow.
5. Откройте Actions → Build Nova Browser APK → Run workflow.
6. После завершения откройте запуск с зелёной галочкой → Artifacts → `NovaBrowser-debug`.
7. Скачайте ZIP артефакта, распакуйте его и установите `app-debug.apk`.

## Важно
Это первая версия и исходный проект, а не готовый проверенный APK. Перед публикацией требуется сборка и тестирование на конкретном телефоне. Используется системный Android WebView, а не движок Blink, встроенный в Chrome отдельно. Не реализованы синхронизация Google, расширения Chrome, менеджер паролей, полноценная защита от трекеров и облачная синхронизация. Приватная вкладка этой версии не обеспечивает полную изоляцию cookies и не делает пользователя анонимным в интернете.
